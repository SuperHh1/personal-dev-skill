# 检查清单（6 张，照着打勾）

> 用法：**动手前扫一遍**。⛔ 不许"心里记得"就算过。
> 每张都对应 `SKILL.md` 的具体守则编号。

---

## 清单 1 · 开工前（⭐ 每次会话开始）

```
[ ] 读了 `SKILL.md`？（P1）
[ ] 读了 `已定事项表.md`？（G1）⛔ 不读不许动手
[ ] 扫了 `挂起表.md`，有没有该接上的？（G2）
[ ] 扫了 `口径表.md`，有没有容易搞错的名词？（G3）
[ ] ⭐ 首次接入的项目：问清三件事了吗？（§〇）
      [ ] 版本控制：git / 快照
      [ ] 项目位置 ⛔ 不在 C 盘；备份位置 ⛔ 不在开发文件夹
      [ ] 对话报告频率
[ ] 有**回档点**吗？（J2/J9）⛔ 没有退路不许开始改
[ ] 本次**能碰什么 / 不能碰什么**写清了吗？（M1）
[ ] 本次"**什么算做完**"写清了吗？（O1）
[ ] 要花钱吗？→ 经人同意了吗？（Q2/E2）
```

## 清单 2 · 读资料前（⭐ 防"取帧不细 / 挖得浅"）

```
[ ] 资料的**形式**是什么？（视频/图/长文档/网页）
[ ] ⭐ 定了**抽取密度**吗？（视频 ≤1 帧/秒；加速视频按内容帧）（F1）
[ ] ⭐ 抽帧位置**扫过一遍定位**吗？（防裁到 UI 控件/黑边）
[ ] 先出**索引表**再下结论吗？（F2）
[ ] 每条结论有**出处**吗？（F3）
[ ] 调研的三层都查了吗？①功能 ②实现 ③许可证/体积/依赖/更新（F4）
[ ] 找到**反面对照**了吗？（F5）⛔ 只写好话＝没查
[ ] 查不到的标 `⏳ 未实测` + 怎么验了吗？（F6）
[ ] 省 token 的手段用了吗？拼贴 / 偏置读 / 指针代替全文（H1~H9）
```

## 清单 3 · 改码时

```
[ ] 这次改的**不超过 2 个文件**吗？（C1）
[ ] 改前**备份**了吗？（C1/J4）
[ ] ⛔ 有没有碰到**冻结的接口签名**？（E2）
[ ] 有没有**顺手加功能/顺手重构**？（M2）⛔ 有就停下
[ ] ⛔ 有没有写 `catch { }` 吞异常？（C3）
[ ] 改判据/加分支**之前**跑了旧版拿基线吗？（A7）
[ ] 报错/异常有没有**带时间戳写进日志**？（J3）
[ ] 有没有 ⛔ **把密钥写进代码/日志/文档**？（N1）
```

## 清单 4 · 交付前（⭐ 三道锁）

```
[ ] **锁①** 第一行是体检输出吗？（B1）⛔ 拿不出 ⇒ 不许说"做完了"
[ ] **锁②** 每个「✅ 已完成」都有指针（文件:行号 / 测试N / 日志+时间戳）吗？（B2）
[ ] **锁③** 验不了的都标 `⏳ 未实测` + 怎么验了吗？（B3）
[ ] **完成定义**三个条件都过了吗？：编译 0 错 ＋ 体检通过 ＋ 亲眼验过一次（O2）
[ ] 回归是"还原基线＋重跑"证明的吗？（A8）⛔ 不许靠推理
[ ] 交付是**四样 + 一行**吗？（§二十四）⛔ 没贴大段代码、没重贴材料
[ ] 该记的**记进表**了吗？（G1/G2/G3/G5）
[ ] 临时产物**清了吗、残留复查了吗**？（C7/D5）
```

## 清单 5 · 选型前（⭐ 照 `选型横评模板.md`）

```
[ ] 表格填了吗？维度含【使用环境】【开发环境】吗？（L1/L2）
[ ] 每个选项有**反面**吗？（L4）
[ ] 有没有 ⛔ **拿厂商口径/印象当证据**？（A2/L3）
[ ] 实测不了的部分标 `⏳ 未实测` + 怎么验了吗？（B3）
[ ] 结论是「选项+后果+推荐」而不是替人拍板吗？（E1）
[ ] 定完**写进 `已定事项表.md`** 了吗？（L5）
[ ] 许可证查了吗？（传染性？商用？署名？）（L/N3）
[ ] ⭐ 改造类选型：是按【止血→划界→统一→下沉】四步排的吗？（L6）
[ ] ⛔ 有没有一上来就"重构"（＝跳到第④步）？（L6）
[ ] 给选项用的是**固定表格**吗？（选项 / 我做什么 / 风险 / 一次改几个文件）（§二十四）
```

## 清单 6 · 收工 / 节点完成（⭐）

```
[ ] 这个**功能模块 / 技术节点**完成了吗？→ ⭐ **提醒用户确认**（J4）
[ ] 用户确认后**保存为"最后正确版"**了吗？（J4）
[ ] ⭐ 备份**滚动**了吗？只留 3 份，多的删掉（J5/J10）
[ ] 备份**放在开发文件夹外面**吗？（J6）
[ ] 云端网盘**备一份**了吗？（J8）
[ ] **版本谱系**记了吗？（J11：哪版好的、哪版试坏的）
[ ] 出了**对话报告**吗？（I3：改了什么/定了什么/卡在哪/下一步/怎么验证）
[ ] 写了**交接**吗？（P2：现状/卡点/下一步）
[ ] 更新 `已定事项表` / `挂起表` / `口径表` / `教训表` 了吗？（G1~G5）
[ ] ⭐ **项目整体完成了吗？**→ 才提醒做"最终备份"（J7）+ 可考虑对外发布（T1）
```

## 清单 7 · ⭐⭐ 大阶段复查（一个模块/一条链/一次改造做完后）

> **起因**：2026-10-03 顺手一挖挖出 103 处空 catch，但当时差点"做完就进下一件"。
> ⛔ **不许"做完了直接进下一件"**（U1）。

```
[ ] ⭐ 这次改动【顺手挖到】了什么问题？（列出来，⛔ 别烂在对话里）
[ ] ⭐ 挖到的问题给【总数】了吗？（例："103 处，41 个文件"，⛔ 不许只说"发现一些问题"）（U4）
[ ] 扫出来的**还没处理的清单落盘了吗**？→ 落文件 ＋ 进 `挂起表.md`（U3）
[ ] 有没有【同类问题在别处】还没查？（一次发现 ≠ 只有一处）（U2③）
[ ] 扫了 `挂起表.md` 吗？有没有【现在可以接了】的？（U2④）
[ ] 新踩的坑进 `教训表.md` 了吗？（U2⑤）
[ ] 新的"已定事项"进 `已定事项表.md` 了吗？（U2⑥）
[ ] ⛔ 复查有没有【擅自扩大范围去改】？（复查是看清，⛔ 不是顺手修）（U5/M2）
[ ] ⭐ 复查结论报给用户了吗？由用户定"改不改、什么时候改"（U5）

### 若这次是【架构/分层类】改造，额外查：
[ ] 是按【止血 → 划界 → 统一 → 下沉】四步走的吗？（L6）
[ ] UI 层有没有 ⛔ 直接 `using Infrastructure`？（V2）
[ ] 有没有 ⛔ `new` 造服务（绕过依赖注入）？（V3）
[ ] UI 占比算了吗？长期 > 40% ⇒ 该下沉（V5）
[ ] 硬编码色值搜了吗？⇒ 应为 0（W2）
[ ] 空 `catch { }` 搜了吗？⇒ 应为 0（W6）
[ ] `async void` 过了一遍吗？只留 UI 事件处理器（W7）
[ ] 三道全局兜底齐了吗？（UI 线程 / 非 UI 线程 / **发了不管的任务**）（W8）
```

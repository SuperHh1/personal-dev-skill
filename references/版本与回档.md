# 版本与回档（J 组落实）

> ⭐ 目标：**任何一步都能退回去**，⛔ 不许"没有退路就开始改"（`SKILL.md` J2）。
> ⚠️ 前提：**有些机器上没装 git** ⇒ 本文件给**两条路**，**由用户自己选**（J1，⛔ AI 不许替选）。

---

## 〇、开工首次必问（照抄去问）

```
本项目版本控制用哪个？
  (a) 装 git  （推荐：能看差异、能回任意点、能分支）
  (b) 备份快照滚动（不需要装任何东西；但只能回到"某一次备份"）

另外两件必须确认（J9）：
  ① 项目目录 ⛔ 不在 C 盘 —— 实际在：________________
  ② 备份目录 ⛔ 不在开发文件夹里 —— 实际在：________________
  ③ 有没有云端网盘同步？（J8）________________
```

## 路线 A · 用 git（装了就用这条）

**基本动作**（每个**节点**做一次，不是每行代码）：
```
1. 开工前：确认工作区干净（没有半截改动）
2. 一个"功能模块/技术节点"做完 → 提交一次，提交信息写人话
3. 提交信息格式：<做了什么>（<为什么>）
      例：加上彩平底图渲染（先出墙窗版，家具版后补）
4. ⭐ 提交前先跑体检（B1），结果一起记进提交信息或交接
5. 阶段完成 → 打个标记（tag/标签），⭐ 名字写人话：
      例：好用的-20261003  /  出图链-第一版
```

**回档动作**：
```
· 只想扔掉刚才的改动   → 丢弃未提交的改动
· 想回到上一个好版本   → 检出那个提交/标签
· 想看看哪儿改坏了     → 比较两个版本
```
⚠️ **⛔ 回档前先把当前状态另存一份**（防"回错了更糟"）。

---

## 路线 B · 备份快照滚动（没 git 就用这条）

### ⭐ 核心规则：**只保留 3 份，多的删掉**（J5 / J10）

```
备份目录（⛔ 不在开发文件夹里）
  ├─ <项目名>_01_最后正确版.zip      ← ① 当前好版本（最重要）
  ├─ <项目名>_02_上一份正确备份.zip  ← ② 上一版（回档就靠它）
  └─ <项目名>_03_进行中.zip          ← ③ 临时包（试坏了就删）
```

**滚动动作**（每次"节点确认"后做一次）：
```
1. 把 02 删掉，把 01 改名成 02          （旧的好版本降级）
2. 把当前代码打包成新的 01              （新的好版本）
3. 03 那份临时包：试成了就删/转正，试坏了直接删
4. ⭐ 顺手看有没有别的旧包 → 删（J10）
```
⇒ ⭐ **效果**：**永远只有 1 份"上一版"可以回**，垃圾不会堆积。

### ⛔ 备份四不许

```
⛔ 不许放进开发文件夹（J6）—— 防误打包、防跟源码混
⛔ 不许只留 1 份（回档就没了）
⛔ 不许留一堆（垃圾越滚越多）
⛔ 不许把密钥/隐私打进包（N1）
```

### ⭐ 什么时候做备份（J4 / J7）

```
✅ 每个"功能模块/技术节点"完成、且【用户确认过】之后
✅ 动手做"风险大的改动"之前（留一个回档点）
⛔ 不是每次改都做（会变垃圾）
⛔ 项目中途不提醒"最终备份"—— ⭐ 项目完成 / 关键节点才提醒（J7）
```

### ⭐ 项目完成时（J7 / J8）

```
[ ] 提醒用户：项目完成，要不要做最终备份？
[ ] 最终备份打包（源码 + 说明 + 用法）
[ ] ⭐ 云端网盘再放一份（J8）
[ ] 备份名写清项目名和日期（S2）
[ ] 更新"版本谱系"（J11）：哪版是交付版、哪版是试验版
```

## 一、崩溃日志（J3）

**要求**：
```
① ⭐ 带【时间戳】（到秒）
② ⭐ 带【上下文】：在干什么、输入是什么、到哪一步崩的
③ ⛔ 不许静默失败（`catch { }` 必须带上报）
④ ⛔ 日志里不许出现密钥/隐私（N1）
⑤ 日志要能被检索（一个功能一个文件，别全塞一个）
```

**日志该写什么**（照抄）：
```
2026-10-03 14:22:07  正在读图纸: 示例图纸.dxf
2026-10-03 14:22:08  读失败: 块 *U27 找不到定义（这是出错点）
2026-10-03 14:22:08  上下文: 图层=20 墙线=211 房间=10
```

---

## 二、版本谱系（J11）

**一张表，记清"哪版是什么状态"**：

| 版本 / 备份名 | 日期 | 状态 | 说明 | 能不能用 |
|---|---|---|---|---|
| 好用的-20261003 | 2026-10-03 | ⭐ 好版本 | 出图链第一版可用 | ✅ 能回 |
| 试验-动态块 | 2026-10-03 | ⛔ 试坏了 | 块基点算错，图偏了 | ⛔ 别用 |

⚠️ **状态只有三种**：⭐ 好版本 / ⛔ 试坏了 / ⚠️ 没验过。
⚠️ **"没验过"的⛔ 不许当"好版本"用**（照 B3）。

---

## 三、回档决策表（改乱了怎么办）

| 症状 | 怎么办 |
|---|---|
| 刚改的没编译过 | 直接丢弃这次改动（C2） |
| 改完能跑，但功能坏了 | 回到上一个"好版本"（路线 A 检出 / 路线 B 用 02） |
| 不知道哪儿坏的 | 比较两个版本，先定位再回（⛔ 别盲目全回） |
| 已经改了好几轮都乱 | ⭐ 先**另存当前状态**，再回上一个好版本，然后**重新小步做**（C1：一次最多 2 个文件） |

## 四、收工三问（顺手做完）

```
[ ] 现在这个状态，算"好版本"吗？（不确定 ⇒ 不算，标"没验过"）
[ ] 备份滚动了吗？（只留 3 份）
[ ] 版本谱系更新了吗？
```

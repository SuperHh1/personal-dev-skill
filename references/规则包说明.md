### ⚠️ 三处都是"清洗过的版本"

```

  · 两份并存最容易漂（实测就漂了：SKILL.md 一处 287 行、一处 163 行）
```

## 二、怎么用（三步）

```
① 开新项目 / 新会话 → 先读根目录的 `SKILL.md` §〇（怎么用）
② 干活时照 25 组守则（A~X）；选型开 `协助分析.md` + `选型横评模板.md`
   架构（分层/动态路由/业务架构）开 `架构推荐说明.md`
③ 交付照「四样 + 一行」：
     一行 = 体检输出
     四样 = 一句话结论 / 改了什么 / 要你决策的一条 / 怎么验证
```

### ⭐ 首次接入一个项目，必须先问清三件事（⛔ AI 不许替选）

```
① 版本控制用哪个？ (a) 装 git  /  (b) 备份快照滚动
② 项目在哪？⛔ 不许在 C 盘；备份位置在哪？⛔ 不许在开发文件夹里
③ 对话报告多久一份？ (a) 每个功能模块  /  (b) 每个技术节点  /  (c) 自定
```

## 四、上传 / 更新到 GitHub

```
双击 `_上传工具\上传到GitHub.bat`
  → 它会先扫一遍有没有夹带密钥（照守则 N1）
  → 让你粘贴 GitHub Token（⛔ 不显示、⛔ 不落盘、用完清掉）
  → 建仓库 → 提交 → 推送 → 打印仓库地址
```

**Token 怎么拿**（3 分钟）：
```
https://github.com/settings/tokens
  → Generate new token (classic)
  → 有效期选 7 days
  → 只勾 repo
  → 复制 ghp_... 那串
```
⭐ **推完请立刻去把那个 Token 删掉。**

⚠️ **注意**：你的全局 `.gitconfig` 里有一条
`url."https://gh-proxy.com/https://github.com/".insteadOf` 代理改写，
而那个代理**现在不通**；脚本会在**仓库级**清掉它，⛔ 不动你的全局配置。
